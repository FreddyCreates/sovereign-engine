# README Insert: THESIS

## THESIS Research Proof Operating System

THESIS is the research proof layer of the Memory Vault.

It turns papers, repositories, drafts, logs, and claims into proof-bounded research packets:

- claims matrix
- evidence map
- proof gaps
- repo verification notes
- public/private release boundary
- PDF/print plan
- hash manifest
- verifier report

THESIS is organized into four release lanes:

| Lane | Purpose |
| --- | --- |
| GPT Marketplace THESIS | Research assistant for packet building, claim hardening, and publication prep |
| Julia Terminal THESIS | Local terminal tool for repo audits, packet generation, hashes, and reproducibility checks |
| THESIS Hub | Workspace for papers, repos, claims, evidence, PDFs, and review state |
| Verifier Mode | Independent diligence layer for funders, reviewers, labs, and researchers |

Core line:

> THESIS verifies research before the world believes it.

See: `thesis/` and `docs/thesis.html`.
