# Tokenomics Engine Spec v1

## Reducers
- Known Context Reducer
- Redundancy Reducer
- Sparse Agent Reducer
- Compression Reducer
- Reuse Memory Reducer
- Risk Preservation Expander

## Core equations
TV = DQ + ACT + RISK + REUSE + LEARN - WASTE

S_i = alpha U_i + beta R_i + gamma M_i + delta T_i + epsilon N_i - zeta K_i

CRPT = Score / TotalTokens

## Runtime
Classify -> Salience -> Budget -> Sparse Route -> Generate -> Compress -> Audit -> Score -> Consolidate.
