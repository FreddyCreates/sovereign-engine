## Reconstruction Steps

1. Read repo intelligence files listed in each paper’s references.
2. Map repo claims into four non-overlapping paper objects: runtime stack, lifecycle loop, proof-score suite, speaking-intelligence loop.
3. Apply claim-boundary rules from THESIS ledgers.
4. Attach external literature only where it supports field context or benchmark precedent.
5. Render PDFs with Pandoc/XeLaTeX.
6. Recompute hash manifest after any edit.
