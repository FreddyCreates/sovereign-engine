# Devpost Hackathon Submission: Parallax Sovereign
**Tagline:** Sovereign AI-Powered Crypto Trading Platform & Agent Forge with RevenueCat In-App Monetization.

---

## 🚀 Inspiration
In today's decentralized finance landscape, traders face fragmented liquidity, slow execution loops, and opaque yield models. **Parallax Sovereign** was built to solve this by creating a unified sovereign chain powered by an 873ms φ-harmonic cycle heartbeat, continuous limit order book (CLOB) matching engine, and an accessible Trading Agent Forge.

---

## ⚡ What it Does
- **Sovereign Ledger & Tokenomics**: Native FORMA token featuring φ-compounding annualised staking rewards ($φ - 1 = 0.618$).
- **Parallax Trading Core**: High-frequency orderbook matching engine (`@parallax/trading-core`) with risk policy gates and clearinghouse settlement.
- **Agent Box Studio**: A web studio allowing users to design, backtest, and deploy custom finance & trading agents (Tunnel Arbitrage, Market Maker, Phantom Signal, Yield Optimizer).
- **ORO Governance Council**: 4-Agent validator council (ARCHON, VECTOR, LUMEN, FORGE) evaluating on-chain state changes via deterministic `TRACE · VERIFY · REMEMBER` proofs.
- **RevenueCat Paywall & Billing Integration**: Seamlessly integrated RevenueCat SDK powering multi-tiered monetization (**Parallax Pro** @ $19.99/mo & **Enterprise Sovereign** @ $99.99/mo), enabling trial activation, entitlement verification, and instant feature unlocking.

---

## 🛠 How We Built It
- **Motoko / Internet Computer**: `forma_ledger.mo`, `agi_terminal.mo`, and `oro_governance.mo` deployed as canister state engines.
- **Rust Core**: `organism-core` consensus layer for φ-harmonic block timing (873ms).
- **TypeScript & Vite**: Modern glassmorphic frontend applications (`parallax-agent-box` & `skyhi-client`).
- **RevenueCat SDK (`@revenuecat/purchases-js`)**: Managed entitlements (`pro_access`, `enterprise_access`), paywall modal, and subscriber state hooks.
