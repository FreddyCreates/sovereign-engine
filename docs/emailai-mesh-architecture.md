```
│  ┌─────────────────────────────────────────────────────────────────────────┐   │

│  │  • Identify entity type: system | organ | agent | human                 │   │
│  │  • Determine priority: critical | high | medium | low                   │   │

│                                      ▼                                          │
│  (4) ROUTING                                                                    │
│  ┌─────────────────────────────────────────────────────────────────────────┐   │

│  │  • Log routing decision for audit                                       │   │
│  └─────────────────────────────────────────────────────────────────────────┘   │
│                                      │                                          │
│                                      ▼                                          │

│  ┌─────────────────────────────────────────────────────────────────────────┐   │
```

## EAP-1 Protocol Flow

```
                              EAP-1 Protocol Flow
══════════════════════════════════════════════════════════════════════════════════

    Sender                         EmailAI Mesh                         Receiver
       │                                │                                   │
       │  ┌─────────────────────────┐   │                                   │
       │  │ Construct EAP-1 Message │   │                                   │
       │  │                         │   │                                   │
       │  │ Headers:                │   │                                   │
       │  │  X-Agent-Type: system   │   │                                   │
       │  │  X-Agent-Intent: task   │   │                                   │
       │  │  X-Agent-Confidence: 0.9│   │                                   │
       │  │  X-Agent-Target: brain  │   │                                   │
       │  │  X-Agent-Priority: high │   │                                   │
       │  │  X-Agent-Thread: uuid   │   │                                   │
       │  │                         │   │                                   │
       │  │ Body:                   │   │                                   │
       │  │  {                      │   │                                   │
       │  │    "intent": "task",    │   │                                   │
       │  │    "payload": {...},    │   │                                   │
       │  │    "metadata": {...}    │   │                                   │
       │  │  }                      │   │                                   │
       │  └─────────────────────────┘   │                                   │
       │                                │                                   │
       │────── (1) Send via SMTP ──────►│                                   │
       │                                │                                   │
       │                                │  ┌─────────────────────────────┐  │
       │                                │  │ (2) Parse EAP-1 Headers     │  │
       │                                │  │ (3) Validate Message        │  │
       │                                │  │ (4) Route to Target Organ   │  │
       │                                │  │ (5) Process Request         │  │
       │                                │  │ (6) Generate Response       │  │
       │                                │  └─────────────────────────────┘  │
       │                                │                                   │
       │                                │────── (7) Route Response ────────►│
       │                                │                                   │
       │  ┌─────────────────────────┐   │                                   │
       │  │ Receive EAP-1 Response  │   │                                   │
       │  │                         │   │◄──── (8) ACK ─────────────────────│
       │  │ Headers:                │   │                                   │
       │  │  X-Agent-Type: organ    │   │                                   │
       │  │  X-Agent-Intent: resp   │   │                                   │
       │  │  X-Agent-Thread: uuid   │   │                                   │
       │  │                         │   │                                   │
       │  │ Body:                   │   │                                   │
       │  │  {                      │   │                                   │
       │  │    "intent": "response",│   │                                   │
       │  │    "payload": {...},    │   │                                   │
       │  │    "result": "success"  │   │                                   │
```
