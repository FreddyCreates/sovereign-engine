# Workspace Project Directives & Production Rules

## Operational Principles for All Agents

1. **Real Production Mindset**: This repository is a real production application built for real competition deadlines and real users. Treat all tasks with practical, production-level engineering rigor.
2. **Zero Fluff & Zero Hypothetical Scale Metrics**: Do not generate hypothetical metrics, pretend subscriber scale, or speculative volume claims (such as 12k subscribers or 100k passes/mo). Ground all metrics, logs, and comments strictly in empirical runtime reality.
3. **Production-Grade Code Quality**: Write clean, maintainable, performant code with real error handling, proper HTTP status codes, and input validation.
4. **Empirical Verification**: Verify all edits with real tests (`pytest`) or live server execution.
5. **Concise, Pragmatic Communication**: Respond directly, concisely, and professionally as a senior software engineer.
